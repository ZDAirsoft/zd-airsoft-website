How publishing works

  1. Add or edit your announcement text.
  2. Review the launcher preview, then select Save and publish.
  3. The secure service commits the JSON file to your website repository.
  4. Your hosting pipeline publishes the change; online SMT24 monitors check approximately every five minutes.

Scheduled messages start and expire automatically on the SMT24, including while offline, provided the message was downloaded before disconnecting and the Android clock is correct. New or edited messages require a website deploy and a launcher refresh.

For safety, feeds containing scheduled messages use format v2. Older launcher builds will keep their previous announcements instead of ignoring schedule dates and showing messages at the wrong time.
