How publishing works

  1. Add or edit your announcement text.
  2. Review the launcher preview, then select Save and publish.
  3. The secure service commits the JSON file to your website repository.
  4. Your hosting pipeline publishes the change; online SMT24 monitors check approximately every five minutes.

This first version does not schedule or auto-expire messages. Disable or remove short-lived messages when they're no longer relevant. Changes won't reach offline monitors until they reconnect.
